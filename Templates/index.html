HOW IT WORKS

From words to insight.

Our system processes your input through a machine learning pipeline to generate a classification.

01

Input

Enter the news headline and complete article into the detector.

02

Process

Headline and article are converted into numerical features using TF-IDF.

03

Compare

The system calculates the consistency between the headline and article.

04

Classify

Logistic Regression analyzes the combined features and generates a prediction.

ABOUT THE PROJECT

Built with Machine Learning.

TruthLens is an academic Fake News Detection project that combines Natural Language Processing, TF-IDF feature extraction, headline–article consistency analysis and Logistic Regression.
